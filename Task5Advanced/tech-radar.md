# Расширенный технический радар

Статусы: 
**Adopt** — применять как стандарт; 
**Trial** — применять в ограниченном контуре (пилот); 
**Assess** — изучать, решение не принято; 
**Hold** — не начинать нового, выводить. 

## Интеграция и события

| #   | Технология / паттерн                  | Статус | Обоснование                                                                        |
| --- | ------------------------------------- | ------ | ---------------------------------------------------------------------------------- |
| 1   | Apache Kafka                          | Adopt  | Ядро целевой событийной платформы; доменные топики, горизонтальное масштабирование |
| 2   | Schema Registry (Avro)                | Adopt  | Версионируемые контракты событий, проверка BACKWARD-совместимости в CI             |
| 3   | Debezium CDC                          | Adopt  | События из легаси-DWH без доработки: стандартный мост миграции                     |
| 4   | DLQ + retry-политики                  | Adopt  | Единые принципы обработки ошибок во всех доменах                                   |
| 5   | Apache Flink                          | Trial  | Потоковая обработка для NRT-витрин; проверяется на пилотных доменах                |
| 6   | Kafka geo-replication (MirrorMaker 2) | Assess | Понадобится при выходе в регионы; оценка вместе с требованиями локализации         |
| 7   | Apache Camel ESB                      | Hold   | Только мост совместимости через ACL; новые интеграции запрещены                    |
| 8   | Точечные синхронные интеграции        | Hold   | Источник связанности;                                                              |
