# TCO-анализ

Все цифры — **модельные оценки в млн ₽/год** для сопоставления структур затрат, а не смета. Параметры модели вынесены отдельно: при подстановке фактических ставок и тарифов модель пересчитывается.

## Параметры модели

| Параметр                                                                          | Значение                                                |
| --------------------------------------------------------------------------------- | ------------------------------------------------------- |
| Аналитики/подготовка отчётности                                                   | 60 сотрудников, полная стоимость 3,6 млн руб/год каждый |
| Платформенная команда (облако, Kafka, дата-платформа)                             | 8 FTE × 3,6 млн руб/год                                 |
| Сопровождение легаси (DWH, ESB, PowerBuilder)                                     | 12 FTE × 3 млн руб/год                                  |
| Разовые затраты миграции (обучение, консалтинг, перенос сотен ТБ, двойной прогон) | 70 млн руб, распределены на 3 года (45/20/5)            |
| Облачная инфраструктура                                                           | растёт по мере миграции: 24 -> 40 -> 48                 |

## Текущая архитектура (AS-IS), в год

| Статья                                                       | млн руб/год | Комментарий                                                          |
| ------------------------------------------------------------ | ----------- | -------------------------------------------------------------------- |
| Лицензии (SQL Server, Windows Server, Power BI)              | 28,0        | коммерческий стек; апгрейд с EOL-версии потребовал бы новых лицензий |
| Инфраструктура on-prem (ЦОД, устаревшее железо, амортизация) | 40,0        | затраты на поддержку устаревшего оборудования                        |
| Сопровождение DWH / ESB / PowerBuilder (12 FTE)              | 36,0        | включая ночные загрузки и разбор инцидентов                          |
| Время аналитиков: ожидание и ручная сборка отчётов (30%)     | 64,8        | 60 × 3,6 × 0,3; отчёты «формируются часами»                          |
| Инциденты и простои                                          | 10,0        | без учёта регуляторных рисков                                        |
| **Итого AS-IS**                                              | **178,8**   | **× 3 года = 536,4**                                                 |
